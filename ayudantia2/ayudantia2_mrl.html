El caso: visitas de videos de YouTube

Pregunta: ¿qué características de un video se asocian con su número de visitas?

Trabajaremos con viral_videos, una base de Kaggle con 12.000 videos simulados (no son datos reales de YouTube), cada uno con:

  • views: número de visitas del video
  • duration_sec: duración del video (en segundos)
  • title_length: número de caracteres del título
  • subscriber_count: número de suscriptores del canal

El modelo de regresión múltiple

Ahora tenemos más de un predictor: la duración, el largo del título y el tamaño del canal.

\[\texttt{visitas} = \beta_0 + \beta_1 \texttt{duracion} + \beta_2 \texttt{largo\_titulo} + \beta_3 \texttt{suscriptores} + \varepsilon\]

  • Modelo 1: solo la duración
  • Modelo 2: duración controlando por el largo del título
  • Modelo 3: además controlamos por los suscriptores del canal

Estimación en R

Estimamos modelos que van sumando predictores (como en clases):

m1 <- lm(visitas ~ duracion, data = videos)
m2 <- lm(visitas ~ duracion + largo_titulo, data = videos)
m3 <- lm(visitas ~ duracion + largo_titulo + suscriptores, data = videos)

En la fórmula, los predictores se suman con +.

coef(m1)["duracion"]

Pasa de -6,1 a -2,1: parte de la asociación negativa entre duración y visitas se debe al tamaño del canal (los videos más largos tienden a estar en canales más pequeños). Al controlar por suscriptores, el coeficiente cambia.

coef(m3)
 (Intercept)     duracion largo_titulo suscriptores 
 143.0936051   -2.0708403    0.2748876    1.6927019

Intercepto (\(\hat{\beta_0}\)): para un video de 0 minutos, título de 0 caracteres y canal sin suscriptores, se esperan 143.090 visitas. Es un valor de referencia, sin interpretación sustantiva por sí solo.

Duración (\(\hat{\beta_1}\)): por cada minuto adicional, las visitas esperadas disminuyen en 2.070 aprox., manteniendo constantes las demás variables (ceteris paribus).

Largo del título (\(\hat{\beta_2}\)): por cada caracter adicional, las visitas esperadas aumentan en 270 aprox., manteniendo constante el resto.

Suscriptores (\(\hat{\beta_3}\)): por cada 10.000 suscriptores adicionales del canal, las visitas esperadas aumentan en 1.690 aprox., manteniendo constante el resto.

Duración: con un 95% de confianza, por cada minuto adicional las visitas esperadas disminuyen entre 1.200 y 2.900, manteniendo constante el resto de las variables.

Intervalos de confianza: a mano

Gráfico de intervalos de confianza

Primero, con R base: extraemos lo que necesitamos del modelo.

ic <- confint(m3)[-1, ]   # IC 95% sin el intercepto
b  <- coef(m3)[-1]        # Coeficientes sin el intercepto
y  <- length(b):1         # Posición en el eje Y (el primero queda arriba)
par(mar = c(5, 12, 3, 2))   # Margen izquierdo amplio para los nombres
plot(b, y,
     xlim = range(ic), pch = 19, yaxt = "n",
     xlab = "Coeficiente (miles de visitas)", ylab = "",
     main = "Coeficientes e IC al 95% (Modelo 3)")
segments(ic[, 1], y, ic[, 2], y)       # Una línea por intervalo
abline(v = 0, lty = 2, col = "red")    # Línea de referencia en 0
axis(2, at = y, las = 1,
     labels = c("Duración (min)", "Largo título", "Suscriptores (10 mil)"))
par(mar = c(5, 4, 4, 2))    # Volvemos a los márgenes originales

Apéndice: error estándar de la regresión

Es el “Residual standard error” de summary(): cuánto se equivoca el modelo, en promedio, en las unidades de \(Y\) (miles de visitas).

\[\hat{\sigma} = \sqrt{\frac{SSR}{n-k-1}}\]

ssr <- sum(residuals(m3)^2)     # suma de residuos al cuadrado

sqrt(ssr / (n - k - 1))         # sigma a mano
[1] 197.9681
sigma(m3)                       # sigma directo del modelo
[1] 197.9681

El modelo se equivoca, en promedio, en unas 198 mil visitas al predecir un video.

Apéndice: error estándar de un coeficiente

Distinto del anterior: mide la precisión con que estimamos un coeficiente (clase 14).

\[se(\hat{\beta_j}) = \frac{\hat{\sigma}}{\sqrt{SST_j \, (1 - R_j^2)}}\]

# Lo hacemos para "duracion"
sigma_m3 <- sigma(m3)                                          # sigma
sst_dur  <- sum((videos$duracion - mean(videos$duracion))^2)   # SST de X
r2_dur   <- summary(lm(duracion ~ largo_titulo + suscriptores,
                       data = videos))$r.squared               # R²_j

sigma_m3 / sqrt(sst_dur * (1 - r2_dur))   # Error estándar a mano
[1] 0.4249814
summary(m3)$coefficients["duracion", "Std. Error"]   # Comparamos con lm()
[1] 0.4249814
